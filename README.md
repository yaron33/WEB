# Accelerator

Animación interactiva de un acelerador de partículas que desemboca
en una esfera de nodos conectados, junto con una reinvención de la
primera página web del CERN.

🔗 **Ver el sitio:** https://accelerator.covao.dev

## Tecnologías
HTML, CSS y JavaScript (canvas).
